# Agent —— 智能体学习笔记

从零到一系统学习 AI 智能体（Agent），涵盖基础理论、LLM 原理、经典范式实战、记忆与检索等核心模块。

## 目录

| 章节 | 内容 |
|------|------|
| 01-初识智能体 | 智能体定义、四大核心要素、传统智能体（AIMA 五分类）vs LLM 智能体 |
| 02-智能体发展史 | 智能体演进脉络与技术沿革 |
| 03-大语言模型基础 | Transformer 架构、模型调用方式、LLM 能力与边界 |
| 04-智能体经典范式构建 | 从零实现 **ReAct**、**Plan-and-Solve**、**Reflection** 三大范式，手写核心代码而非依赖封装框架 |
| 06-构建你的智能体框架 | 工程化智能体框架设计 |

## 适合人群

- 想系统理解 AI Agent 底层原理的开发者
- 准备面试中 Agent 相关内容的求职者

## 核心哲学

> 手动造轮子是为了理解轮子——不依赖 LangChain 等高度封装框架，从零实现每个模块，吃透智能体的底层运行机制和工程取舍。
